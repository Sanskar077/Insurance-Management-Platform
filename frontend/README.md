# Frontend — Insurance Management Platform

React + TypeScript + Vite + Tailwind CSS frontend.

See the root [README.md](../README.md) for full project setup instructions.

## Scripts

- `pnpm dev` — start the dev server
- `pnpm build` — typecheck and build for production
- `pnpm preview` — preview the production build
- `pnpm lint` / `pnpm lint:fix` — lint the codebase
- `pnpm format` / `pnpm format:check` — format the codebase
- `pnpm typecheck` — run TypeScript without emitting output
